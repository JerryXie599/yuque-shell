# Yuque Shell (语雀轻量绿色客户端)

> 完全绿色免安装、数据便携隔离、支持离线阅读与无阻编辑的轻量 Windows 语雀桌面客户端。

---

## ✨ 特性一览

- 🚀 **纯净绿色免安装**：解压即用，无任何安装向导，不写注册表，不往系统盘遗留垃圾文件。
- 💾 **数据全便携存储**：所有登录凭证、本地镜像文档、知识库离线缓存及 WebView 数据全部存放在程序同级目录的 `data/` 文件夹中，**绝不侵占 C 盘空间**，拷贝整个文件夹即可无缝换机使用。
- ⚡ **原生 Windows 体验**：基于 Windows 原生 WebView2 与 GUI 子系统打造，启动静默无黑框命令行，流畅轻巧、低内存占用。
- 🌐 **网络环境隔离**：原生直连语雀官方服务，隔离各类系统代理或 VPN 环境变量的异常干扰。
- 🛡️ **内置常驻助手**（窗口右下角胶囊图标，随时展开）：
  - **【完全直连】**：直连语雀官方服务，并在后台自动增量镜像缓存已浏览的文档和插图。
  - **【手动离线】**：一键断网走本地镜像模式，离线状态下打开文档即可直接编辑，无任何报错弹窗阻碍，编辑内容安全进入本地暂存队列。
  - **【立即同步】**：将本地暂存的文档修改与图片有序提交至语雀云端，同步完成后自动维持安全状态。
  - **【后台缓存知识库】**：一键对当前所在知识库进行整库递归扫描与预取，断网环境下也能随时查阅整库文档。

---

## 📥 下载与使用

1. 前往本仓库 [Releases](../../releases) 页面，下载最新的便携压缩包：
   - **`yuqueshell-portable.zip`**
2. 解压到电脑任意非系统盘目录（例如 `D:\Software\YuqueShell` 或移动硬盘中）。
3. 双击运行 **`yuque-shell.exe`**。
4. 在弹出的窗口中登录你自己的语雀账号，即可直接使用。

---

## 🗂️ 目录结构说明

解压并启动后，目录结构如下：
```text
yuqueshell/
├── yuque-shell.exe     # 客户端主程序
├── 使用说明.txt         # 离线与同步功能使用说明
└── data/               # 首次启动自动生成，保存所有用户数据与离线镜像
    ├── webview/        # 独立的浏览器会话、Cookie 与登录凭证（与系统 Edge 完全隔离）
    └── yq-offline-mirror/ # 本地知识库离线镜像库与离线草稿暂存队列
```

> **便携提示**：如需迁移到其他电脑，只需将整个 `yuqueshell/` 文件夹复制过去，依然保持原登录态与离线缓存。若需彻底卸载，直接删除整个文件夹即可，不留任何系统残留。
